# Gravity Falling

**Gravity Falling** is a quick prototype where you fall endlessly and dodge obstacles as gravity shifts around you. Try to survive as long as possible and beat your high score!

🎮 **How to Play**
- Move left/right using **[insert controls: e.g., A/D or Arrow Keys]**
- Avoid obstacles while falling
- Watch out for sudden gravity flips!
